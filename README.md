# Automotive B-Pillar Crash Strength & Structural Optimization Using FEA

## Project Overview

A collaborative automotive engineering project completed at the University of Windsor, focusing on improving the lateral crash strength and structural performance of an automotive B-pillar using Finite Element Analysis (FEA).

The project investigates the structural response of an existing B-pillar design under lateral loading and explores reinforcement modifications to improve stiffness, reduce displacement, and enhance crash resistance.

## Project Objectives

- Evaluate the lateral crash strength of the original B-pillar design.
- Analyze structural displacement and Von Mises stress under loading.
- Investigate the response of the B-pillar to a target lateral force of 140 kN.
- Develop reinforcement modifications to improve structural performance.
- Compare the original and modified B-pillar designs.

## Tools & Technologies

- ABAQUS — Finite Element Analysis
- HyperMesh — Model Preprocessing and Meshing
- Finite Element Modeling
- Structural Stress and Displacement Analysis
- Automotive Body-in-White (BIW) Design

## Methodology

1. Examine the original automotive B-pillar geometry.
2. Prepare the model and generate a finite element mesh.
3. Define material properties, boundary conditions, and applied loads.
4. Perform structural analysis using ABAQUS.
5. Evaluate displacement and Von Mises stress distributions.
6. Introduce reinforcement modifications to the B-pillar.
7. Analyze and compare the structural performance of the modified design.
